INTEGRATION DETAILS
===================

API Endpoint: POST https://crop.kindwise.com/api/v1/identification

Request Headers:
- Content-Type: application/json
- Authorization: Bearer {KINDWISE_API_KEY}

Request Body:
{
  "images": ["base64_encoded_image"],
  "details": ["treatment", "description", "url", "taxonomy", "symptoms", "severity", "spreading"]

TROUBLESHOOTING
===============

401 Unauthorized:
- API key is incorrect or expired
- Environment variable not set
- Check KINDWISE_API_KEY in Vars section

Rate Limit Exceeded:
- Wait 5-10 minutes
- Check API usage quota
- Consider upgrading plan

Image Too Large:
- Resize image to smaller dimensions
- Ensure file is under 10MB
- Try JPEG format instead

No Diseases Found:
- Image may not be clear enough
- Try different angle or lighting
- Ensure crop is visible in image
