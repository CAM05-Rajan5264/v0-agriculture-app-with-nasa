TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════════

Problem: "API Key Not Configured"
────────────────────────────────────────────────────────────────────────────────
Solution:
   1. Open Settings → Vars
   2. Verify PLANT_ID_API_KEY exists
   3. Check value: 2b106T6wt500zga8mnEmtoDu
   4. If missing, add it now
   5. Wait 30 seconds
   6. Hard refresh (Ctrl+Shift+R)
   Time: 2 minutes


Problem: "Invalid image format"
────────────────────────────────────────────────────────────────────────────────
Solution:
   1. Image must be: JPG, PNG, or GIF
   2. Image size: Less than 5MB
   3. Try different image or format
   Time: 1-2 minutes


Problem: "Not a plant detected"
────────────────────────────────────────────────────────────────────────────────
Solution:
   1. Upload image containing a plant
   2. Ensure plant is clearly visible
   3. Try better lighting (natural daylight)
   4. Plant should fill most of frame
   Time: 3-5 minutes


Problem: Still not working?
────────────────────────────────────────────────────────────────────────────────
Solution:
   1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
   2. Check browser console: F12 → Console tab
   3. Look for [v0] messages
   4. Check internet connection
   5. Review IMAGE_ANALYSIS_ERROR_HANDLING.md for detailed error help
   Time: 2-5 minutes


BEST PRACTICES FOR PHOTOS
══════════════════════════════════════════════════════════════════════════════════

✓ DO:
  • Take in natural daylight
  • Focus on the affected leaf/area
  • Fill frame with plant
  • Ensure image is sharp
  • Use smartphone or good camera
  • High resolution (1000x1000+ pixels)

✗ DON'T:
  • Shoot in shadows or poor lighting
  • Use blurry/out-of-focus images
  • Include too much background
  • Upload multiple plants
  • Use files larger than 5MB
  • Use unrelated objects


BROWSER CONSOLE DEBUGGING (F12)
══════════════════════════════════════════════════════════════════════════════════

To check if system is working:

1. Press F12 (or Cmd+Option+I on Mac)
2. Click "Console" tab
3. Upload an image
4. Look for messages starting with [v0]

Success messages:
   [v0] API Key check - Key exists: true
   [v0] Sending image to plant.id API for analysis...
   [v0] API response received in 8234 ms
   [v0] API Status: 200 OK

Error messages:
   [v0] API Key check - Key exists: false  ← Need to add API key
   [v0] ERROR: Invalid API Key  ← Key is wrong
   [v0] Network error  ← Internet issue
